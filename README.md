One line of honest software error copy for the [make.fun](https://make.fun) bounty "Say What Actually Broke": the brutal truth about what went wrong, funny on a single read.

> The payment went through twice because the retry button works and the first charge did too. Call your bank, not us.

`main.ts` writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
